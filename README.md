# Masari: Oman Graduate Employment Guide

COMP3700 – Introduction to Web Computing  
Sultan Qaboos University – Fall 2026

## About the Project

Masari is a website that helps students in Oman explore university majors and learn about possible career opportunities.

In Part III, I updated the website using Bootstrap 5 and JavaScript to make it responsive and interactive.

## Website Features

- Explore and compare university majors.
- View sample graduate employment data.
- Search for and add majors, careers, and employment records.
- Complete a feedback questionnaire.
- Use a skill-learning calculator.
- Play a simple career-related game.

## Technologies Used

- HTML
- Bootstrap 5
- JavaScript

## Project Information

This project was developed for COMP3700 at Sultan Qaboos University.

Some employment information is sample data used to demonstrate the website's features. The registration and login pages are demonstrations and do not create real accounts.
