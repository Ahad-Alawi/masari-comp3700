# Masari - Part III (COMP3700)

Student website project by Ahad Nasser Al Alawi, Sultan Qaboos University.

## Open the website
Open index.html in a browser (needs internet, since Bootstrap is loaded from a CDN link).

## What changed in Part III
- Removed the old style.css and inline styles, all pages now use Bootstrap only
- Added a responsive navbar, grid layout and Bootstrap form styling/validation
- Carousel and modal on the home page (2 interactive Bootstrap components)
- careers.html and trends.html now build their tables from JavaScript arrays
  (Career and EmploymentRecord objects), with add + search forms
- New pages: questionnaire.html (feedback form with custom validation),
  calculator.html (skill learning time estimator), funpage.html (guess the
  major game)
- Scrolling welcome banner with live date/time on the home page

## Notes
- Employment numbers are sample data, not real statistics
- Registration and advisor forms are demos; no account or saved questions are created
- The Contact page prepares an email draft in your email application; the user must send it
- Still need to: push to GitHub with commit history, upload to a host, and
  write the Part III report (screenshots, contribution table, etc.)

## Before you submit
1. Check each page in Chrome and in a narrow mobile-sized window.
2. Try adding and searching data in Careers and Trends. Added rows are temporary.
3. Submit invalid and valid feedback, test the calculator, and finish the game.
4. Check that the homepage slideshow changes after 3.5 seconds and the clock updates.
5. Upload the website to GitHub and your web host, then prepare the Part III report.

The gallery uses three supplied SQU photographs (clock tower, graduation, campus).
The images switch automatically every 3.5 seconds.

All form interactions are client-side. Avoid entering real passwords into demo forms.
